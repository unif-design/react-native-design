## 视觉规范

来源：`src/components/ui/Stepper/styles.ts`、`Stepper.tsx`。

| 元素 | 规则 |
|---|---|
| 实际交互 frame | `−` / `+` outer 固定 44×44；中央 adjustable outer 至少 44×44，均直接读取 `fixed.hitTarget`，不经过 `r()` 或 fontScale |
| visual 高度 | md 为 `r(32)`（Web / 402pt RN harness 是 32px）；sm 为 28px（`control.sm`） |
| 圆角 | 8px（`radius.md`，外层左右两角），中间数字框无独立圆角 |
| 按钮 visual | md `r(32) × r(32)` / sm 28×28，嵌在 44×44 outer 内并朝中央贴边；`±` 字号 18px（`type.h1`） |
| 数字 visual | md `r(48) × r(32)` / sm `r(40) × 28`，在中央 outer 内居中；1px 上下边线、无左右边线，字号 md 14 / sm 13 |
| 背景 / 描边 | `c.surface` 底 + 1px `c.outline`（亮色 `#EDEDED`）边 |
| 禁用 | 按钮 `opacity: 0.4`（达到 min/max 或整体 `disabled` 时；按下 0.7） |

## 用法

```tsx
import { Stepper } from '@unif/react-native-design';

const [qty, setQty] = useState(12);

<Stepper
  value={qty}
  onChange={setQty}
  min={1}
  max={99}
  accessibilityLabel="商品数量"
/>

{/* 自定义步长 */}
<Stepper
  value={packs}
  onChange={setPacks}
  step={6}
  min={0}
  max={120}
  accessibilityLabel="整箱数量"
/>

{/* 小尺寸 */}
<Stepper
  size="sm"
  value={n}
  onChange={setN}
  min={0}
  max={9}
  accessibilityLabel="套餐数量"
/>

{/* 原始 min > max 会折叠为零范围：显示 10，三个操作节点全部禁用 */}
<Stepper
  value={5}
  onChange={setQty}
  min={10}
  max={0}
  accessibilityLabel="异常范围数量"
/>
```

## API

来源：`src/components/ui/Stepper/types.ts`、`Stepper.tsx`。

| Prop | Type | 默认 | 说明 |
|---|---|---|---|
| `value` | `number` | — | 当前值（受控，必填） |
| `onChange` | `(value: number) => void` | — | 变更回调（已自动夹到 `[min, max]`，必填） |
| `accessibilityLabel` | `string` | — | 中央 adjustable 的上下文名称（必填）；左右按钮自动组合“`${label}，减少` / `${label}，增加`” |
| `min` | `number?` | `0` | 下限（达到时 `−` 禁用） |
| `max` | `number?` | `99` | 上限（达到时 `+` 禁用） |
| `step` | `number?` | `1` | 步长（非正数 / 非有限数回退为 1） |
| `size` | `'sm' \| 'md'` | `'md'` | visual 高度 28 / `r(32)`；三个 outer 的 44pt 约束不变 |
| `disabled` | `boolean?` | `false` | 整体禁用（三个操作节点都不暴露 action） |
| `testID` | `string?` | — | 根定位；派生三个 outer `-decrement` / `-value` / `-increment` 与对应 `-*-visual` |

> 归一化边界：缺省仍是 `min=0`、`max=99`、`step=1`。非有限 `min` 回退 0；显式非有限 `max` 或 `max < safeMin` 时折叠到 `safeMin`，形成零范围；非正数 / 非有限 `step` 回退 1。`value=NaN` 使用 `safeMin`，`±Infinity` 分别钳到上下边界。零范围与外部 `disabled` 都不会暴露任何 action。无 `style` prop。

## 无障碍（a11y）

来源：`src/components/ui/Stepper/Stepper.tsx`、`types.ts`。

- 默认 `accessibilityRole`：`−` / `+` 两个 outer `<Pressable>` 是 `'button'`；中央 outer `<View>` 是 `'adjustable'`。根 `<View>` 不设 role，内部 visual 子树隐藏出 a11y tree。
- accessible name：必填 `accessibilityLabel` 直接命名中央 adjustable；左右按钮分别组合为“`${accessibilityLabel}，减少` / `${accessibilityLabel}，增加`”，页面存在多个 Stepper 时也保留业务上下文。
- 单一归一化结果同时驱动可见值、disabled opacity、handler、`accessibilityValue` 和 `accessibilityActions`。到 `safeMin` 只暴露 `increment`，到 `safeMax` 只暴露 `decrement`；对应无效侧按钮同时设 disabled 并移除 handler。
- 外部 `disabled` 或零范围时，中央上报 `disabled: true`，并完全省略 `accessibilityActions` 与 `onAccessibilityAction`；两个侧按钮也都 disabled 且没有 handler。

```tsx
<Stepper
  value={qty}
  onChange={setQty}
  min={1}
  max={99}
  accessibilityLabel="统一冰红茶数量"
/>
```

## Native / Web 人工测量

在 runtime harness 的 Stepper 区用 Inspector 测量：

| 节点 | testID | 预期布局 |
|---|---|---|
| 左右 outer RNGH Pressable | `stepper-middle-decrement` / `stepper-middle-increment` | 所有平台固定 44×44，透明、无 `hitSlop`；visual 朝中央贴边 |
| 中央 adjustable outer | `stepper-middle-value` | 所有平台至少 44×44 |
| md visual wrappers | 对应 `-decrement-visual` / `-value-visual` / `-increment-visual` | 实现为 `r(32)×r(32)` / `r(48)×r(32)` / `r(32)×r(32)`；Web 与 402pt RN harness 是 32×32 / 48×32 / 32×32，其他 native window 按实际 `r()` 结果 |
| sm visual wrappers | `stepper-zero-range-*-visual` | 28×28 / `r(40)×28` / 28×28；outer 仍为固定 44×44 |

用 screen reader 检查 `stepper-min-value` 只提供增加、`stepper-max-value` 只提供减少；`stepper-zero-range-value` 必须上报 disabled 且没有 adjustable action。点击无效侧按钮或零范围任意节点，harness 的 unexpected 计数必须保持 0。

## 不要

- ❌ 不要在 Stepper 中间放可输入的 TextInput——下单场景请用专门的 InputNumber 控件（待规划）
- ❌ 不要省略或复用无上下文的 `accessibilityLabel`——名称应说明正在调整哪个业务值
- ❌ 不要去掉描边或圆角——Stepper 必须看起来"可点击"
