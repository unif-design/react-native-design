# 使用建议

| 目标             | 做法                                                 |
| ---------------- | ---------------------------------------------------- |
| 保持亮暗主题一致 | 从主题 Hook 取得颜色和阴影，使用公开设计变量         |
| 复用样式计算     | 将 `useThemedStyles` 的样式工厂定义在模块顶层        |
| 保持组件边界     | 从包根导入公开组件，不读取其他组件未导出的样式或状态 |
| 正确传递交互状态 | 按 API 提供受控值、事件和必要的无障碍名称            |
| 适应应用字号     | 使用已有字体能力，避免对同一字号再次缩放             |
| 表达业务流程     | 应用决定查询、确认和提交，组件只展示状态与交付事件   |
| 验证跨平台行为   | 文档站预览用于 Web，原生手势、键盘和设备行为另行验证 |

具体尺寸、颜色、图片、动效和宿主行为见[组件文档](../components/overview.md)；设计取舍见[设计原则](principles.md)。
